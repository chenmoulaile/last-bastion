## 关键坑
- Windows 大小写不敏感：`CharacterSelect.tscn` 与 `character_select.tscn` 冲突 → 放 `scenes/ui/survivors/`
- Godot 新增 `class_name` 后必须跑一次 `--import` 刷新 global class cache，否则全项目解析失败
- 程序化地形：固定比例放拾取点会落坑 → `_ground_point_near()` 向两侧探测
- 漫画 shader：色阶必须 `floor()`，四舍五入会把暗部抬亮成灰雾；描边采样 2px 避雨滴
- Label 先设 size 再设 autowrap 会被最小尺寸撑开 → 先 autowrap 再 size
