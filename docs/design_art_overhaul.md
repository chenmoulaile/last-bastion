# 美术重做设计 · v3.3.0 Art Overhaul

> 目标：参照《破门而入：行动小队》(Door Kickers: Action Squad) 的画风，重做人物 / 僵尸 / 枪械 / 建筑美术，
> 达到"粗颗粒手工像素"质感。允许使用生图模型（ImageGen），预算受控、杜绝浪费。

## 1. 风格基调（对齐 DK:AS）

- **粗颗粒像素**：先高清生成，再严格降采样到精确像素网格，统一 32 色脏色板量化 → 真正的像素颗粒，而不是"高清图缩小的糊感"。
- **强轮廓**：所有角色/僵尸/道具加 1px 深色描边（DK:AS 标志）。
- **重光影**：2–3 阶明暗 + 单侧强边缘光（夜战霓虹/月光感），暗部压重。
- **脏色板**：末世军绿 / 灰蓝 / 锈棕为基调，血红与警示黄做高饱和点缀。
- **动态姿势**：人物统一带前倾战斗姿态，僵尸有轮廓各异的病态体态。

## 2. 生成管线（ImageGen → Pillow → Godot）

1. 生成 1 张**风格锚定图**（突击兵精修立绘），后续全部素材用 img2img + 锚定图保证风格统一。
2. 每个角色生成 1 张**姿势表**（idle/run/shoot/melee/hurt/die/crouch/slide/jump 关键姿势网格）。
3. Pillow 脚本 `tools/gen_ai_sprites.py`：切片 → 降采样到精确网格 → 色板量化 → 描边 → 拼装横向动画条带 → 输出与现有**完全同名**的 PNG。
4. Godot 侧零改名的替换集成（SpriteLibrary 按文件名加载，自动生效）。

## 3. 分辨率升级（数据驱动，改动点已确认）

| 资产 | 现在 | 升级后 | 代码改动 |
|---|---|---|---|
| 角色帧 | 32×32 | **48×48** | player.tscn Sprite 偏移 -16→-24 |
| 角色立绘 portrait | 40×40 | 48×48 | 无（按纹理绘制） |
| 僵尸（普通） | 24×32 | 36×48 | zombie_*.tres `sprite_size` |
| 僵尸（Tank） | 64×64 | 96×96 | 同上 |
| 武器 | ~28×10 | ~40×14 | 无（同文件名替换） |
| 建筑/背景/道具 | 现尺寸 | 同尺寸重绘 | 无 |

视口 640×360 + 最近邻过滤不变；角色屏占比 9%→13%，更接近 DK:AS 的体格感。

S1 结束后先出游戏内对比截图给用户确认风格，再花 S2 的积分。

## 5. 动画方案（省积分的关键）

- **角色**：姿势表提供真实关键帧（跑/射击/倒地），中间帧程序补齐（bob/剪切/镜像）。
- **僵尸**：每个僵尸 1 个基础姿势（分组表切片），全部动画程序派生：idle 呼吸、run 蹒跚、attack 前扑、hurt 后仰、die 塌倒旋转。
- **动画帧数/时长表不动**（SpriteLibrary.CHAR_ANIMS / ZOMBIE_ANIMS 原样）。
