LAST BASTION v3.2.0 · two-process co-op verification
=====================================================

Topology
--------
Two independent Godot processes on one machine, ENet over 127.0.0.1:7777.
Host creates the room and immediately starts L01; the client joins and receives
the synchronized level start. Both processes were also run with a real window
for the screenshots (--capture).

Lifecycle implemented
---------------------
1. Main menu -> "联机合作 ONLINE" -> Host (创建房间) or Join (IP).
2. Host: NetworkManager.host_session() + start_coop_level(L01).
3. Client connects -> host sends rpc_start_level -> both load L01.
4. LevelRunner names the local body Player_<peer_id>, sets multiplayer authority.
5. Client level ready -> rpc_client_level_ready -> host spawns Player_<client>
   and sends the host body to the client.
6. Two-phase replication handshake: spawn nodes on both sides, then host asks
   clients to enable synchronizers, receives acks, then enables its own.
   This avoids Godot SceneCache permanently caching missing node paths.
7. Host spawns zombies -> rpc_zombie_spawn -> client visual copies (AI disabled).
   Host broadcasts position at 20 Hz; clients interpolate.
8. Client shots send rpc_zombie_damage to the host; the host applies damage,
   broadcasts death/dismember; clients remove the visual copy.
9. Player shots broadcast rpc_player_shot; remote peers play muzzle flash,
   tracer, positional gunshot and impact blood (presentation only).

Known limits (not tested / not production-grade)
------------------------------------------------
- Only 2 processes on loopback; no 3-4 player, NAT, packet loss or jitter test.
- Zombie damage from clients is host-arbitrated, but the client also applies
  local damage for immediate feedback; this is a co-op trust model, not anti-cheat.
- Late join after a fight is supported by the spawn handshake but not stress-tested.
- No host/join lobby UI beyond the dialog; no ready/kick/character select.
- Remote shooting is presentation + host damage; it is not a rollback/lag-
  compensated netcode.
