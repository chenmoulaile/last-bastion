Fixes that made the old suites green
------------------------------------
- PlayerControllerV2 had no CollisionShape2D and never applied gravity in the
  normal physics branch. Pickups (Area2D body_entered) could never fire and
  jumping/landing was cosmetic. Added the 12x28 collider and gravity.
- LevelRunner never connected EventBus.player_died to on_player_died, so
  checkpoint respawn and COMMAND "commander death fails run" never ran.
- Ported the legacy revive/black-and-white/medkit/pills rules into
  PlayerControllerV2 (first revive 30 temp HP; second black-and-white max_hp=1;
  medkit restores max HP; pills add 50 temp HP).
- Added start_rappel/_tick_rappel so WindowRappel interaction works.
- Regression test fixes: GDScript lambdas capture scalar locals by value, so
  the HealthComponent test now records through a Dictionary; bool(null) in the
  stealth test; the reload test now sets a half magazine and polls the 70%
  cancel window instead of assuming a specific reload time.
