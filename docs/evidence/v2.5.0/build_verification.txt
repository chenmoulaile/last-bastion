Note on the first export
------------------------
The first export of this build launched but emitted:
    WARNING: Faction data missing: horizon
    WARNING: Faction data missing: signal_bureau
    WARNING: Faction data missing: rust
    WARNING: Faction data missing: remnants

Root cause: exported PCKs store converted resources as "name.tres.remap",
while GameManager / FactionManager / ArchiveManager filtered for ".tres".
The data directories were therefore empty inside the exe. The loaders now
strip ".remap" and also accept ".res"; the numbers above are from the
re-exported build.

Scope caveat
------------
This is a startup/data-load verification, not an automated full playthrough.
The same level table is used by GameManager.start_level, so the campaign can
start; no scripted end-to-end mission was run inside the exported exe.
